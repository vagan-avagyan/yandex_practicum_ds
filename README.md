## 🚀 Как начать работу

1. Клонировать репозиторий и перейти в папку:
   ```bash
   cd yandex_practicum_ds
   ```

2. Создать виртуальное окружение и установить зависимости (при наличии `requirements.txt`):
   ```bash
   pip install -r requirements.txt
   # или: pip install polars jupyter
   ```

3. Запустить Jupyter и открыть нужный ноутбук проекта:
   ```bash
   jupyter notebook
   ```
